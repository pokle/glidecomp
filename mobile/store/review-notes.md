# App Review notes — draft

For App Store review and Play's pre-launch review.

GlideComp scores hang gliding and paragliding competitions. Most of it
works signed out: open any competition under Comps to see its tasks, scores
and report cards.

To try the signed-in parts, sign in with the demo account:

- Email: <demo account address — to be created before submission>
- The app emails a 6-digit code. The demo account's mailbox is <how the
  reviewer reads it, e.g. a shared inbox, or a fixed code configured for
  that one address — decide before submission>.

The demo account is the organiser of a hidden test competition,
"<name>", so the organiser screens can be tried without changing a real
competition.

Notifications are opt-in per competition (a competition's Notifications
row) and are only asked for at that moment.
