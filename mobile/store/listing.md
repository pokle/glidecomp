## Description

GlideComp runs hang gliding and paragliding competitions, and explains them.

For pilots:
- Submit your track from the landing paddock, with or without signal — it waits on the phone and sends when it can.
- See the scores, and a report card for every flight that shows how each point was earned, with the arithmetic.
- Send the day's task to your instrument: an XCTrack task file, waypoint files for every common format, or a QR code to scan at the briefing.
- Follow a competition and hear when your track is in, when a task's route is set, and when the scores move.

For organisers:
- Run the day from the hill: create the competition and its tasks, set the route, manage the roster, mark pilots absent, apply penalties, upload on a pilot's behalf, and recompute the scores.
- Every change is written to the competition's public activity log.

Scoring follows the FAI Sporting Code (CIVL GAP), and every decision on a report card can be checked against the rules.
