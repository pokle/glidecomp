### Executive summary

**No new findings this round; `bun audit` clean of anything new (still the
3 dev-time `astro` advisories carried since 2026-07-26); no Critical.** The
window's two substantive changes both got a full read rather than a
diff-skim. First, `web/workers/competition-api/src/routes/comp.ts`'s audit
logic was rewritten so a GAP-parameter change is described against the
category (Wing) it will actually be scored under — `resolveCompGapParams`
merges a stored partial over `defaultsFor(category)`, not the raw engine
baseline, so diffing against the wrong baseline was reporting knobs the
organiser never touched (issue #633) — and the Wing's own copy inside the
formula (`gap_params.scoring`) is now forced to follow the Wing on every
write (`withWingScoring`), closing a state where the two could silently
disagree. This is a correctness/audit-fidelity fix, not a security
boundary: the route's `requireAuth`/`requireCompAdmin`/Zod-validation stack
is untouched, every value still reaches the database only via `.bind(...)`,
and the resolved values feed a human-readable audit sentence, never a
sink — verified by tracing `describeGapParamChanges`/`compFieldTable`
through to `auditAll`, which writes plain-text descriptions the audit-log UI
already escapes (unchanged since SEC-22/41). Second, the old 21-control
`SettingsDialog.tsx` (592 lines, now deleted) was replaced by a routed
hierarchy — `CompSettingsIndex` plus four focused sub-pages under
`web/frontend/src/react/comp/settings/` — each PATCHing only its own
group's fields through the same typed `api.*` client the dialog used, gated
client-side by the same admin-email check the dialog used (cosmetic only;
`requireCompAdmin` is what actually enforces it) and server-side by the
unchanged route guard. None of the five new components introduce a DOM
sink, a `dangerouslySetInnerHTML`, or a dynamically-built `href`/`src` — the
one new `href` (`ScoringSettings.tsx`'s `/scoring/gap#defaults-${wing}`) is
built from a literal-typed `"hg" | "pg"` derivation of `comp.category`, not
free text. `functions/comp/[[path]].ts` correctly adds the new
`/comp/:id/settings(/:group)?` paths to the existing admin-only/noindex
shell-route list rather than SSR'ing or indexing them. The four mobile-nav/
tab-strip commits and the new mobile Playwright project are UI/test-only —
the background sweep found no new sink, storage use, or non-relative fetch
anywhere in that surface, and the pre-existing same-origin click-guard
logic was moved verbatim (not weakened) into a new shared hook. `bun audit`
composition is byte-for-byte the same 3 `astro` dev-time advisories as the
last two rounds.
